## 레이아웃 검사

- 각 페이지 본문은 `page-body` 안전 영역 안에 배치되어 머리글·바닥글 공간과 분리됩니다.
- 편집 후 `https://se0sangh0.github.io/portfolio/?layout-check=1`을 열면 본문 높이 초과나 머리글·바닥글 침범 페이지가 빨간색으로 표시됩니다.
- 콘솔에서도 `window.portfolioLayoutCheck()`을 실행하면 자동 맞춤 후 문제 페이지 목록을 다시 확인할 수 있습니다.
