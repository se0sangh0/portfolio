# 서상호 · 게임·시스템 기획 웹 포트폴리오

게임에서 출발해 보안·산업 모니터링·IoT·웹까지, **문제 정의 → 시스템 설계 → 검증**이라는 한 가지 방식으로 기획한 기록을 담았습니다.

## 보기

- **온라인:** https://se0sangh0.github.io/portfolio/
- **GitHub 프로필:** https://github.com/se0sangh0

현재 원본은 **index.html**, **styles.css**, **app.js**입니다. 별도 빌드 과정 없이 GitHub Pages에서 동작합니다.

## 화면 구조

- 기본 주소에서는 작업대 위의 닫힌 노트가 먼저 나타나고, 노트를 누르면 확대되며 포트폴리오가 펼쳐집니다.
- 열린 노트 오른쪽에는 10개의 포스트잇 목차가 붙어 있으며, 모바일에서는 같은 목차를 짧은 측면 탭으로 표시합니다.
- 넓은 화면에서는 중앙 링 제본을 기준으로 연속된 두 쪽을 함께 보여 주고, 작은 화면에서는 한 쪽 보기로 전환합니다.
- 제목·대표 이미지 면은 여백을 유지하고, 관련된 상세 기록은 가독성을 해치지 않는 범위에서 같은 쪽에 묶습니다.
- 포스트잇은 각 분류의 첫 면을 열고, 문서 좌우 가장자리·이전·다음 버튼·방향키는 선택한 분류 안의 펼침 또는 페이지를 넘깁니다.
- 열린 노트는 정상 화면에서 세로 스크롤 없이 동작하며, 매우 큰 글자 확대나 낮은 가로 화면에서는 내용 유실을 막는 쪽 내부 안전 스크롤만 허용합니다.
- 각 기록은 #inspector, #thermoguard 같은 주소로 바로 열 수 있습니다.
- 페이지 전환 효과는 prefers-reduced-motion 설정에서 자동으로 꺼집니다.
- 자바스크립트를 사용할 수 없거나 인쇄할 때는 모든 기록이 세로 문서로 이어집니다.

## 괴이탐사국 최근 소식

- 대구게임인재육성사업 예비 창업팀 선정.
- 2026 대만 이노테크 전시회 동상·특별상, 같은 전시회에서 함께 진행된 2026 태국 발명전시회 특별상 수상.
- Steam 출시 준비. 스토어 페이지는 2026년 12월부터 2027년 2월 사이 개설 예정이며 게임 출시일과 구분합니다.
- 한국·일본·중국·대만 등의 민간 설화를 재해석하는 세계관 방향을 소개합니다.

## 공개 범위

- ThermoGuard에는 회사명·현장명·네트워크 주소·장비 식별자·실제 운영 데이터·팀원 실명을 넣지 않습니다.
- 팀 프로젝트는 확인 가능한 본인 역할만 기여로 표시합니다.
- 실장비 장기 운영이나 현장 실증이 끝나지 않은 기능은 완료 성과로 표현하지 않습니다.
- 수상·교육 자료는 공개용 사본만 사용하며 연락처·학번·일련번호 등 불필요한 개인정보를 제외합니다.
